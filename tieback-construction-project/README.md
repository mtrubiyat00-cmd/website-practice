# Tieback Construction Website

A React + Vite frontend with three routes: Home (`/`), About Us (`/about`), and Contact Us (`/contact`).

## Build
- Install dependencies with `npm install`
- Run locally with `npm run dev`
- Create a production build with `npm run build`

## Vercel
Import this GitHub repository into Vercel. The Vite framework is detected automatically. Build command: `npm run build`; output directory: `dist`. `vercel.json` includes SPA rewrites for React Router refreshes.

## Contact form
The contact form validates fields in the browser but intentionally does not send or store submissions. Connect a form backend before accepting inquiries through the form.

## Social links
Social icons are intentionally non-clickable until official profile URLs are provided.
